## 在系统中查看

管理员登录后，进入管理页面的知识管理，选择以“宁大·”开头的新分类。打开条目，可查看正文摘录、适用范围、发布日期、时效说明和原文链接。核对后可以使用现有发布按钮，发布时自动生成本地 Embedding 向量；普通用户在发布前不能通过普通搜索或语义搜索访问草稿。

每条知识是一段原文，不是完整政策。回答申请资格、完整材料清单等问题，需要结合原文其他条款和附件；不能根据单个检索分段直接判定用户符合资格。

## 资料保存位置

- `raw/`：网页阅读工具实际返回的逐行可见内容快照。不是原始 HTML，不是下载完成的 PDF、Word 或表格。
- `text/`：去除导航和重复移动版内容后的正文，附来源和适用范围。
- `corpus.json`：来源、正文、摘要校验值、正文分段和未选用记录，供复现导入。
- `import-report-*.json`：实际导入报告，包含本批新增知识编号。
- `verification.json`：入库数量、分类、状态、来源和本地快照核对结果。

部分附件下载入口要求验证码，未绕过验证，也没有读取其内容。附件名称仅用于定位原文件，不作为附件正文依据。单纯图片、抓取失败或缺正文的页面未导入；不能把页面标题或搜索摘要当作全文。

特别注意：历史转专业通知引用 2021 年文件，而 2026-10-26 的专项选拔通知已经引用宁大政〔2026〕75号，现行普通转专业细则仍需另行核对。学院通知不能泛化为全校规定。部分原网页本身日期表述存在差异，条目已保留疑点，不擅自修改原文。

## 重新整理和导入

在项目根目录执行：

```powershell
.\database_experiment\Scripts\python.exe scripts/import_nbu_official.py prepare
.\database_experiment\Scripts\python.exe scripts/import_nbu_official.py import --admin admin --dry-run
.\database_experiment\Scripts\python.exe scripts/import_nbu_official.py import --admin admin
```

`prepare` 仅整理已保存的网页快照，不会联网重新采集。正式导入默认草稿，按官方来源地址和分段文件名识别已有记录，重复执行不覆盖管理员修改或发布状态。原文发生变化时，应另行核对版本，不直接覆盖已审核资料。
